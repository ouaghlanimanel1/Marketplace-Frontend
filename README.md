
# Marketplace Frontend

## Overview
A modern web application built with Angular and TypeScript. Inspired by Facebook Marketplace, this project features a dynamic user interface for browsing listings, managing user-generated items, and facilitating direct interactions between buyers and sellers.

## Features
- User interface for browsing products
- Product listing and management interfaces
- Integration with backend REST APIs
- Responsive web interface

## Technologies
- Angular
- TypeScript
- HTML5
- CSS3
- REST APIs

## Getting Started

### Prerequisites
- Node.js
- npm
- Angular CLI

### Installation
```bash
git clone (https://github.com/ouaghlanimanel1/Marketplace-Frontend)
cd Marketplace-Frontend
npm install
```

### Run the application
```bash
ng serve
```

Open `http://localhost:4200` in your browser.

## Backend
The frontend communicates with a Spring Boot backend through REST APIs.

Backend repository: (https://github.com/ouaghlanimanel1/Marketplace-Backend)
